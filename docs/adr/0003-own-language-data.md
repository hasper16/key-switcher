# Build our own language data; do not reuse the original's

Rekey for Windows is modelled on the macOS app Rekey, whose bundle ships 42 ready-made language JSON files. We do not copy them, its UI texts, or its server addresses: they are the original author's work. Language Profiles are generated by our own tool from openly licensed word-frequency lists, and the tool's sources and licences are recorded next to the generated data.
