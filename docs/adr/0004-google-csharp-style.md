# Google C# Style Guide instead of .NET defaults

Code follows the Google C# Style Guide (2-space indent, 100-column limit, opening braces on the same line, `_camelCase` for all non-public fields including constants), not the Visual Studio / .NET defaults (4 spaces, Allman braces). The project owner chose it explicitly; `.editorconfig` encodes it and StyleCop rules that contradict it (SA1500, SA1201, SA1303, SA1306, SA1309, SA1101) are disabled on purpose — do not "fix" formatting back to .NET defaults. One deliberate deviation from the guide: comments are written only for non-obvious logic (the owner's commenting rule), and XML docs are required on public members only, worded per `docs/conventions/xml-docs.md`. Commit messages follow Conventional Commits 1.0.0, enforced by `.githooks/commit-msg`.
