# Rekey for Windows

Rekey fixes a word typed in the wrong keyboard layout (`ghbdtn` becomes `привет`) and switches the
layout for you. It runs in the background as a tray app. It is a Windows analog of the macOS app
Rekey, written from scratch in C# / .NET 10 and WPF.

> **Status:** early development. The app starts in the notification area, keeps one instance per
> user session and stores its settings, but it does not correct text yet. The plan is in
> [docs/roadmap.md](docs/roadmap.md).

## Prerequisites

- Windows 10 or 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0): 10.0.403 or a later 10.0
  feature band (pinned in `global.json`)

## Build, test, run

```bash
dotnet build
dotnet test
dotnet run --project src/Rekey.App
```

`dotnet build -c Release` builds the release configuration. Warnings fail the build: the
analyzers (SonarAnalyzer.CSharp, StyleCop.Analyzers and .NET code style) run in every build.

Rekey shows an **R** icon in the notification area; right-click it and choose **Quit** to exit.
Settings are stored in `%LOCALAPPDATA%\Rekey\settings.json`.

After cloning, turn on the repository's Git hooks (commit message format, secrets, formatting,
Core tests):

```bash
git config core.hooksPath .githooks
```

## Project layout

| Path | Contents |
|---|---|
| `src/Rekey.Core` | Pure .NET logic: the engine (events in, actions out) and settings; no Windows APIs |
| `src/Rekey.Win32` | Windows adapters; Win32 calls are generated by CsWin32 from `NativeMethods.txt` |
| `src/Rekey.App` | WPF host: tray icon, start-up and shutdown |
| `tests/` | xUnit v3 tests for `Rekey.Core` and `Rekey.Win32` |
| `openspec/` | Specs and planned changes (spec-driven workflow) |
| `docs/` | Roadmap, architecture decisions (`docs/adr/`) and conventions |
